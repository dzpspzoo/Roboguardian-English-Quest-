# Roboguardian English Quest

Darmowa gra przeglądarkowa do nauki angielskiego dla dzieci, które słabo rozróżniają angielskie dźwięki
(ADHD, afazja, czytanie „polską fonetyką”). Gracz odbudowuje robota AEGIS-7, który chroni rodzinę naukowców.

- Zagraj: https://dzpspzoo.github.io/roboguardian-english-quest-/ (po włączeniu GitHub Pages)
- Zasady kodu i podział na moduły: [docs/ARCHITEKTURA.md](docs/ARCHITEKTURA.md)
- Uruchomienie lokalne: `python -m http.server 8000` w tym katalogu, potem http://localhost:8000

Wyniki dzieci są zapisywane tylko w ich przeglądarce. Gra nie wysyła żadnych danych.
